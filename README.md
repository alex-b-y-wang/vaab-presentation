# VAAB — Group 02 presentation

CSIT998 Professional Capstone Project, The No-Coders.

This repository contains the HTML presentation and English speaking scripts.

- Open the GitHub Pages website to view the presentation.
- Press **Right / Space** to advance, **N** for speaker notes, **G** for the contents, **F** for fullscreen, and **H** to hide controls.
- Each slide includes the speaker, target duration, narration, and animation cues.
- Download `speaking-scripts.txt` from the notes panel for rehearsal.
- The demo slide is a placeholder; the video has not yet been inserted.
- Any in-browser text edits are local to that browser. They do not update the shared site.

## Publishing

GitHub Pages serves the root of the `main` branch. The site is plain HTML, CSS and JavaScript, with its fonts and images embedded. No build step is needed.

Update `index.html` and `speaking-scripts.txt` together to keep the slides and scripts aligned.
